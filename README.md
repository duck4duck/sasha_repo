# Справочник акций Белтелеком

Локальное веб-приложение на **Node.js, Express и MySQL** для поиска акций по параметрам клиента. В нём есть две страницы: «Акции» и «Тарифы». Данные в `database/seed.sql` перенесены из предоставленного фрагмента; перед рабочим использованием их следует сверить с первичными документами и официальным сайтом.

## Важное замечание к первоначальной структуре БД

В исходной таблице `promotions` был один столбец `categories_id`. Одна акция может относиться одновременно к нескольким услугам (например, к телевидению и пакетам услуг), поэтому в проекте добавлена связующая таблица `promotion_categories`. Также `number_code` сделан уникальным вместе с `client_type`: номера акций могут повторяться у физических и юридических лиц. Поле цены тарифа допускает `NULL`, потому что в присланном материале цены не указаны. Если эти изменения неудобны, сначала согласуйте модель с руководителем практики.

## Пошаговый запуск с нуля

1. Установите Node.js LTS и MySQL Server. Откройте MySQL Workbench или консоль MySQL.
2. Создайте папку проекта и откройте её в VS Code: `mkdir beltelecom-promotions && cd beltelecom-promotions && code .`.
3. Скопируйте все файлы этого проекта в созданную папку, сохранив структуру: `public/`, `database/`, `server.js`, `package.json`.
4. В терминале VS Code установите библиотеки: `npm install`.
5. В MySQL Workbench откройте по очереди `database/schema.sql` и `database/seed.sql`, затем нажмите кнопку выполнения. Первый файл создаст чистую БД `dbBelt`, второй заполнит её начальными данными.
6. Скопируйте `.env.example` в `.env`: `cp .env.example .env`. В Windows создайте копию файла вручную или выполните `copy .env.example .env`.
7. Откройте `.env` и укажите пользователя и пароль MySQL. Например: `DB_USER=root`, `DB_PASSWORD=ваш_пароль`. Не добавляйте `.env` в Git: он уже указан в `.gitignore`.
8. Запустите приложение: `npm start`. В браузере откройте `http://localhost:3000`. Для разработки с автоматической перезагрузкой сервера используйте `npm run dev`.
9. Чтобы добавить новую категорию, тариф или акцию, внесите SQL-запрос в конец `database/seed.sql` и выполните его в Workbench. Для акции обязательно добавьте связи в `promotion_categories`; если она действует на конкретные тарифы — в `promo_compatible_tariffs`.
10. Перед передачей проекта проверьте синтаксис командой `npm run check`, а затем вручную проверьте фильтры, раскрытие карточки, переключение «Карточки/Таблица» и страницу тарифов.

## Как устроен поиск

* «Новый» клиент автоматически получает стаж `0`, и поле стажа блокируется.
* Категории выбираются множественно. После их выбора список тарифов содержит только тарифы выбранных категорий.
* Флаг расторжения показывает акции, отмеченные как программы удержания. Дополнительные условия, ограничения и обязательства скрыты до кнопки «Подробнее».
* Звёздочка у скидки означает несколько этапов скидки; точная схема выводится в подробностях.

## Структура проекта

* `server.js` — Express-сервер и API для MySQL.
* `public/` — клиентская часть: разметка, оформление и логика фильтров.
* `database/schema.sql` — создание таблиц.
* `database/seed.sql` — начальные категории, тарифы, акции и их связи.
